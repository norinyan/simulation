# 仿真平台使用手册

## 1. 容器管理

本节命令在宿主机的 `simulation_new` 项目根目录执行。

### 1.1 构建镜像并启动容器

```bash
docker compose -f docker/compose.yaml up -d --build
```

### 1.2 启动容器与查看状态

```bash
# 启动已有容器；容器不存在时会创建
docker compose -f docker/compose.yaml up -d

# 查看容器状态
docker compose -f docker/compose.yaml ps
```

### 1.3 进入容器

```bash
docker compose -f docker/compose.yaml exec dev bash
```

### 1.4 停止并移除容器

停止并移除容器及 Compose 创建的网络，保留项目源码和镜像。

```bash
docker compose -f docker/compose.yaml down
```

## 2. 仿真运行

本节命令在容器内执行。通过 launch 文件统一启动与手动启动二选一。

### 2.1 构建 ROS 2 工作空间

通过 launch 文件统一启动前，先加载 ROS 2 环境并构建相关包。

```bash
cd /workspace
source /opt/ros/humble/setup.bash
colcon build --packages-up-to sim_bringup
```

### 2.2 通过 launch 文件统一启动

构建完成后，在同一终端加载工作空间环境，启动 Gazebo Classic、加载三层楼场景并生成机器人。

```bash
source install/setup.bash
ros2 launch sim_bringup sim.launch.py
```

### 2.3 手动启动

以下命令均在已加载 ROS 2 环境的容器终端中执行。

#### 启动 Gazebo 并加载世界

以下两条命令二选一。

```bash
# 启动 Gazebo，加载空世界
ros2 launch gazebo_ros gazebo.launch.py
```

```bash
# 启动 Gazebo，加载三层楼世界
ros2 launch gazebo_ros gazebo.launch.py world:=/workspace/src/sim_bringup/worlds/three_floor.world
```

#### 生成机器人

Gazebo 启动后，在另一个容器终端中执行，将机器人生成在世界坐标 `(0, -6.3, 0.32)` 处。

```bash
ros2 run gazebo_ros spawn_entity.py \
  -entity wheel_leg_robot \
  -file /workspace/src/control/urdf/robot.urdf \
  -x 0 -y -6.3 -z 0.32
```
